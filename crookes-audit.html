Desktop Performance 57 — worse than mobile, caused by 561KB of unused JavaScript
Lighthouse identifies 561KB of unused JavaScript on the page — code loaded by GoDaddy's platform that the site doesn't actually use. This is the main driver of a desktop performance score of 57, which is worse than the mobile score. On a fast desktop connection, visitors wait 2–3 seconds before the site becomes interactive purely due to JavaScript the page doesn't need. The Trabelo rebuild loads zero framework overhead — every byte served is content the visitor actually sees.
✓ Fixed — zero unused JavaScript, desktop perf 99
📱
Speed Index 12.1 seconds on mobile — venue visitors checking times and events on their phones wait over 12 seconds
Speed Index measures how quickly the page looks complete to a visitor. At 12.1 seconds, someone searching "what's on Crookes Club tonight" on their phone is waiting over 12 seconds before the page feels loaded. This is the scenario that matters most for a social club — people checking events, times and ticket links on their phones, often just before heading out. A Speed Index of 12.1s means many of them close the tab and check Facebook instead.
✓ Fixed — Speed Index under 1 second on mobile
♿
Accessibility 76 on desktop — buttons with no names, missing alt text, insufficient colour contrast, broken heading order
Lighthouse flags: buttons without accessible names, images without alt attributes, links without discernible names, colour contrast failures, and heading elements not in sequentially-descending order. Accessibility 76 on desktop is a significant failure across multiple categories. This matters for three reasons: (1) it excludes users with disabilities and screen readers, (2) Google uses accessibility signals in search ranking, and (3) it directly contributes to the Agentic Browsing score of 2/3 — meaning AI tools can't fully read the site.
✓ Fixed — Accessibility 98, all WCAG 2.1 issues resolved
🤖
Agentic Browsing 2/3 — AI tools, voice assistants and Google's AI Overview can't fully read the site
An Agentic Browsing score of 2/3 means the site's accessibility tree is not well-formed — AI agents, voice assistants (Alexa, Siri, Google Assistant), and Google's AI-generated summaries in search results cannot fully interpret the content. When someone asks "what's on at Crookes Club this week?" to their phone assistant, a broken accessibility tree means the answer can't be extracted from the site. With AI search growing rapidly, this will increasingly affect discoverability.
✓ Fixed — fully navigable by AI agents and voice assistants
🗓️
No live events calendar — events are manually updated as static image/text blocks
Every event on the current site is a static image manually placed on the page, with ticket links typed in by hand. There is no integration with TicketSource (where they already sell tickets), no calendar view, no way for visitors to see all upcoming events in one place, and no automated way to keep the site up to date. The What's On page is currently empty apart from a Elton and the Jets banner. A proper events system would pull from TicketSource via API or a simple CMS, keeping the site always current with zero manual effort per event.
⚡ New feature — live events card + TicketSource links
🔍
SEO 85 mobile / 92 desktop — robots.txt invalid and images missing alt text both flagged
Lighthouse flags two SEO issues: a robots.txt file that returned an error (meaning search crawlers may be partially blocked), and images without alt attributes throughout the site. These combine to produce an SEO score of 85 on mobile. For a Sheffield venue competing for searches like "live music Sheffield", "social club Sheffield" and "function room hire Sheffield S10", these are fixable ranking factors that are being left on the table.
✓ Fixed — valid robots.txt, all images with alt text, SEO 100
📅
Copyright © 2018 — the site hasn't been structurally updated in 8 years
The site footer reads "Copyright © 2018 Crookes Club." While content is occasionally updated (events are added, some pages exist), the underlying structure, template, navigation and design have not changed since GoDaddy's 2018 website builder was used to create it. In that time, mobile usage has overtaken desktop, Google has introduced Core Web Vitals as ranking signals, and AI-powered search has become mainstream. The 2018 template cannot accommodate any of these developments.
