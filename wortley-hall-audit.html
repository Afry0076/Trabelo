What's Not Working — and Why It Matters

These are the specific problems I found on your current site, explained in plain terms with what each one means for guests visiting the site.

Critical

The site is slow to load on mobile — 5.9 seconds before anything appears on screen

What's happening

Google's mobile test shows it takes 5.9 seconds for the first thing to appear on screen, and 9 seconds before the main content loads. Certain files are blocking the page from even starting — adding nearly 4 extra seconds of delay on their own.

What this means for Wortley Hall

Most couples browsing wedding venues are doing it on their phones in the evenings. Research consistently shows that more than half of mobile users leave a site that takes over 3 seconds to load. At 9 seconds for your key content, a meaningful number of your potential enquiries are leaving before they've seen anything. Given the value of a single wedding booking, this is the most pressing issue on the site.

The fix

A rebuilt site removes the render-blocking files, compresses images properly (your current site is loading over 2.8MB of data per visit — around 3x more than it needs to), and delivers pages in under 2 seconds on mobile.

Critical

Images aren't optimised — the site is carrying unnecessary weight on every page load

What's happening

Google's test found potential image savings of 1,429KB — that's a significant amount of data being sent to every visitor that doesn't need to be. Images also lack defined dimensions, which causes the page to visually jump around while loading (Google calls this Cumulative Layout Shift, and yours scores 0 — fine — but this is in spite of, not because of, how the images are set up).

What this means for Wortley Hall

For a venue that sells itself on its beauty, the irony is that heavy, unoptimised images are making the site load slowly and look less polished than it should. A guest on a standard mobile connection gets a sluggish experience — which doesn't match the quality of the Hall itself.

The fix

All images are compressed, converted to modern formats (WebP), and sized correctly — so the site loads fast without sacrificing image quality on screen.

Accessibility

Forms, links and images are missing labels — meaning some visitors can't use them

What's happening

Google found that form fields don't have proper labels, links don't have readable names, and some embedded content (iframes) is missing title information. There's also a contrast issue — some text doesn't stand out clearly enough against the background. These are the issues dragging your Accessibility score down to 80.

What this means for Wortley Hall

Around 1 in 5 people in the UK have a disability of some kind. Accessibility issues mean screen readers — used by people with visual impairments — can't properly navigate your site. For a venue that prides itself on welcoming everyone, it's worth getting this right. It also matters for search rankings, as Google increasingly favours accessible sites.

The fix

A rebuilt site is built with proper semantic HTML from the ground up — all form fields labelled, all links descriptive, all media correctly described. Target score: 98+.

Code Quality

Unused and unminified JavaScript and CSS is slowing things down further

What's happening

Google found 197KB of unused JavaScript, 86KB of unused CSS, and additional savings available from minifying (compressing) both. This is code your site loads but never actually uses — dead weight on every page visit.

What this means for Wortley Hall

Every extra kilobyte of unused code is time your visitor spends waiting. This is a common symptom of an older WordPress or page-builder setup — it accumulates over time as plugins are added and removed.

The fix

A hand-built site with no bloated frameworks or unused plugins — only the code that's actually needed, properly compressed.

Trust & Security

Several security headers are missing — a flag for more cautious users and for browsers

What's happening

Google flagged missing CSP (Content Security Policy), HSTS, COOP and X-Frame-Options headers. These are technical settings that tell browsers how to behave when loading your site. They don't affect what visitors see, but they're increasingly expected as a baseline for any modern website.

What this means for Wortley Hall

Some corporate clients visiting for conference enquiries may have stricter browser security settings. Beyond that, it's simply good hygiene — and a sign that the site hasn't had a technical update in a while.

The fix

All standard security headers are properly configured as part of the rebuild and deployment setup.
